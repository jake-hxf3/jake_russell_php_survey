# PHP Survey Webpage
![header image of a globe and apples](images/geo-about.jpg)

This project is about implementing a geography survey questionnaire using PHP form techniques. It uses POST method and PHP functions to perform validation of data.

## Installation
No installation required, simply download the zip file and extract.
## Usage
Open index.html in your browser and decide if you pass the quiz.
